# #248: Materia screen planner

## Goal
Pad plans for the Materia screen, in `semantic/materia-screen.js`, that a later native Materia panel (UI lane) can run:
- `materiaColumnPlan(from, to)`: the slot cursor along a row (Left/Right). It covers only columns 0-1, which #244 confirmed (`MATERIA_CONFIRMED_COLUMNS` = 2).
- `materiaListPlan(from, toSlot)`: the list cursor to any inventory slot, moving over list index = `materiaListOffset + materiaListRow`, one entry per press, never wrapping (`MATERIA_INVENTORY_SLOTS` = 200). Each step also carries the expected `{ row, offset }`.
- `materiaListStep(pos, button)`: Down moves the row until row 9, then scrolls (#244). Up moves the row until row 0, then scrolls back (H2).

A plan executor runs the list plan with `materiaListSlot(row, offset)` as its cursor (unit test).

## Save
`harness/saves/disc1-md1stin-materia-plan.json` is `disc1-md1stin-materia-gaps` with author-chosen materia 49 only in inventory slots 2, 7 and 13, with AP 2, 7 and 13 (words 0x249, 0x749, 0xd49).

## Hypotheses
- **H1:** Down past row 9 scrolls one entry whatever the slots hold, so index = slot past page 1 across gaps.
- **H2:** Up after a scroll moves the row first, with the offset unchanged.

## Attempt 1 (`save-boot-27a`, `27b`), generated by `runner/test/unit/materia-plan-scenarios.js`
- **27a:** `materiaColumnPlan(0, 1)` (one Right), Circle to open the list for weapon slot 1, `materiaListPlan({0,0}, 13)` (13 Downs, to row 9 offset 4), then Circle. Slot 13 should empty into weapon slot 1.
- **27b:** open the list for weapon slot 0, plan to slot 13, then `materiaListPlan({9,4}, 7)` (6 Ups, to row 3 offset 4), then Circle. Slot 7 should empty into weapon slot 0.

Each press waits for the cursor that should move (the row, or the offset on a scroll) and checks the other in one frame.
